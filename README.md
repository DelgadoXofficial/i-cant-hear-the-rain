# i-cant-hear-the-rain
Gabriel's Website — https://icantheartherain.com

Plain static site, no build step.

- `index.html` — home page (story, podcast, hearing dog, support, follow)
- `shop.html` — merchandise preview page
- `assets/` — images
- `favicon*.ico` — site icons

Preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000
